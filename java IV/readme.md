Java IV — Festivali që përshtatet në çdo ekran

-Çfarë realizova

Në këtë detyrë krijova një faqe interneti për një festival shkencor, duke përdorur HTML5 dhe CSS3. Faqja përmban një menu fleksibile, një pjesë hyrëse, gjashtë karta aktivitetesh dhe një seksion informues.

Për dizajnin përdora Flexbox, CSS Grid dhe media queries, në mënyrë që faqja të përshtatet me madhësi të ndryshme të ekraneve.

-Teknologjitë e përdorura

HTML5 – për strukturën dhe përmbajtjen e faqes.

CSS3 – për dizajnin dhe ngjyrat.

Flexbox – për organizimin e menusë.

CSS Grid – për paraqitjen e kartave të aktiviteteve.

Media queries – për përshtatjen e faqes në telefona, tableta dhe kompjuterë.

-Kur do të zgjidhje Flexbox dhe kur Grid?

Flexbox do ta përdorja kur dua t'i rreshtoj elementet në një drejtim, horizontalisht ose vertikalisht, për shembull te menuja e faqes. Grid do ta përdorja kur dua t'i organizoj elementet në rreshta dhe kolona, për shembull te kartat e aktiviteteve. Në këtë projekt i përdora të dyja, sepse secila është e përshtatshme për një pjesë të ndryshme të faqes.
